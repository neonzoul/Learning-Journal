# Learning Journal

> **Before I knew how to build software, I learned by leaving a trail.**

**Archived — no longer maintained.**

This repository is a snapshot of the period when I was learning software development by building things.

Not through a single course or a carefully designed curriculum, but through experiments, small projects, broken ideas, notes, and questions that appeared while trying to make things actually work.

## What this was

This was my digital notebook.

I used it to explore programming fundamentals and gradually move into areas I found more interesting:

- Python and JavaScript
- APIs and integrations
- asynchronous programming
- automation
- application structure
- small tools and experiments

Some things here are incomplete. Some approaches are awkward. Some experiments went nowhere.

That is part of the point.

The repository captures how my understanding changed while I was still forming it.

## Why it is public

Most portfolios show only finished work.

I wanted to keep at least one record of the period before the finished work existed.

This repository shows the messy part: learning something, trying it, misunderstanding it, rebuilding it, and slowly developing better questions.

I am not maintaining or cleaning it up because doing so would make it less useful as a historical snapshot.

If you are reading the code, treat it as a record of learning rather than an example of my current engineering practices.
